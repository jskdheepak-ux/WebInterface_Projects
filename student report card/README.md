# Student Report Card Application

A React application built with Vite and React Router to view students and their academic report cards.

## Features

- **Home**: Welcome page introducing the application.
- **Students**: Displays student list with roll numbers and link to individual report cards.
- **Report Card**: Detailed view showing marks for each subject (Tamil, English, Maths, Science, Social), total marks, average, grade, and pass/fail result.

## Getting Started

### Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
