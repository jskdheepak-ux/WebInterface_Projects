# Student Registration & Report Card System

A React application built with Vite and React Router for registering students and viewing their detailed academic report cards.

## Features

- **Student/User Registration:** Register new students with Roll Number, Name, and subject marks (Tamil, English, Maths, Science, Social).
- **Persistent Data:** Stored in browser `localStorage`, initialized with sample student data (`Priya`, `Sona`, `Miro`).
- **Student Directory:** View all registered students, search by name or roll number, and delete records.
- **Report Card:** Detailed breakdown per student showing marks, total out of 500, percentage, subject grades, and pass/fail status.
- **Responsive & Clean UI:** Clean styling matching the dark-and-light card aesthetic.

## How to Run

1. Open a terminal in this project directory:
   ```bash
   npm run dev
   ```
2. Open the URL shown in your terminal (usually `http://localhost:5173`) in your browser.
