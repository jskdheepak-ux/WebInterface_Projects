## Aim
To design and develop a Personal Portfolio Website using React, CSS and React Router that displays personal information, skills, projects and contact details through different navigable pages.

---

## Tech Stack
- **React 18**
- **React Router DOM (v6)**
- **Vite**
- **Vanilla CSS (App.css)**

---

---

## How to Run the Project

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

---

## Pages and Features
- **Home (`/`):** Welcome greeting, intro, and call-to-action button.
- **About (`/about`):** Brief bio and technical skill tags (HTML, CSS, JavaScript, React, Java, Python).
- **Projects (`/projects`):** Project showcase cards with description and tech stack.
- **Contact (`/contact`):** Contact information with email, phone, and location.
